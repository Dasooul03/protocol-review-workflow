# 技术协议智能评审工作流

输入待评审协议文件，统一解析为 Markdown 后，结合业务规则完成评审，输出修改建议、待确认事项及对应原文。

参数提取与规则检索并行执行；候选项并行处理，单项内部串行执行。每项最多纠正一次，全部候选完成后汇总。图中省略关键词入库等辅助支线。
